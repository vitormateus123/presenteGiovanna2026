# Para Giovanna

Presente de aniversário feito com React e Vite, pensado primeiro para celular.

## Rodar localmente

```bash
npm install
npm run dev
```

## Construir

```bash
npm run build
```

A galeria e os vídeos reais aguardam a seleção de arquivos. As cinco perguntas são provisórias e podem ser ajustadas em `src/main.jsx`.
